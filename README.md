## 投资理念

- 极端悲观是反转前奏，而非加速离场的信号。AAII看空近48%时，坏消息往往已被市场提前消化；[@ArtofSpecuycky](https://x.com/ArtofSpecuycky/status/2064941032635351349) 与 [@hanking66](https://x.com/hanking66/status/2064952491016646679) 均指出：真正的底部恰是恐慌最盛时，届时反而更少人敢买。

- 最优质的资本配置来自"用自身盈利再投产"的企业，而非依赖持续融资扩张CapEx的公司。[@ShanghaoJin](https://x.com/ShanghaoJin/status/2065008286886416500) 指出半导体最优赛道是拥有产能的fab，以及能锁定fab产能的fabless公司。

- 市场总有听起来合理的卖出理由，定力比预测更值钱。[@BrianFeroldi](https://x.com/BrianFeroldi/status/2065026878230921533) 援引格雷厄姆经典理念：保持定力、避免被短期情绪驱动决策。

- 优质公司不等于好投资，估值与买入时机同样关键。[@charliebilello](https://x.com/charliebilello/status/2064912850670297204) 数据显示主要IPO首年中位回报-31%、最大回撤-53%，即便是SpaceX级别的标的也需警惕上市溢价陷阱。

- 产业链底层的结构性短缺（InP、MLCC、ABF载板）往往比表层的股价涨跌更早反映周期拐点，供应链数据是领先于市场情绪的Alpha来源。[@jukan05](https://x.com/jukan05/status/2064919388411883930) / [@labubu_trader](https://x.com/labubu_trader/status/2064952434213130321)
